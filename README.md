# money-management
支出を可視化し、最小限の入力でお金の流れを把握できるWeb家計簿アプリ

## 概要

Money Management は、支出の動きを可視化し、
日々の支出管理を目的とした Web 家計簿アプリです。

家計簿の入力が手間に感じて継続できないという課題を解決するため、
シンプルな構成と入力のしやすさを重視して設計しました。

##  目的

支出の登録と月別・カテゴリ別の集計に機能を絞り、
最小限の入力で支出の傾向を把握し、
お金の管理ができることを目的としています。

## 背景

私自身、支出管理が苦手で、気付くと収入よりも支出が多くなってしまう事がありました。

既存の家計簿アプリを試したものの、継続して入用することができませんでした。
また、自分が求めていた機能を満たすものがなかったことも課題でした。

そこで、支出管理に対する心理的ハードルを下げるため、使いやすいＵＩと
シンプルな設計にこだわり、自分が本当に使い続けたいと思える家計簿アプリを自ら開発しようと考え、
本アプリの制作に至りました。
